## 📌 Executive Overview / Yönetici Özeti

This repository contains a **battle-tested, production-grade legal and technical contract suite** governing an enterprise Software-as-a-Service (SaaS) and headless commerce backend platform.

Bu depo, büyük ölçekli bir e-ticaret kuruluşu ile kurumsal bulut yazılım şirketi arasındaki tüm hukuki, ticari ve teknik ilişkileri düzenleyen **eksiksiz, iki dilli (Türkçe ve İngilizce) sözleşme, teknik şartname ve SLA/SLO paketini** içerir.

### 🏢 Fictional Case Study & Engaged Parties / Örnek Proje ve Taraflar

*   **Customer / E-Commerce Enterprise (Müşteri):**
    *   **ApexRetail Global A.Ş. / ApexRetail Inc.**
    *   A tier-1 omnichannel retailer serving **10M+ Monthly Active Shoppers**, processing up to **50,000 checkout orders/hour** during peak shopping festivals.
*   **Vendor / SaaS Provider (Hizmet Sağlayıcı):**
    *   **CloudScale Systems Yazılım A.Ş. / CloudScale Systems Inc.**
    *   An enterprise cloud-native software and managed high-concurrency microservices provider.
*   **Project Title (Proje):**
    *   **OmniStore SaaS & Unified Commerce Engine**
    *   A headless commerce backend with real-time distributed inventory locking, intelligent multi-acquirer payment gateway orchestration, and event-driven order management.

## ⚡ Operational Service Level Metrics (SLO/SLA)

| Metric | Normal Target | Peak / Cyber Week Target | Remedy / Enforcement |
| :--- | :--- | :--- | :--- |
| **System Availability** | **≥ 99.95%** (Max 21.9m downtime/mo) | **≥ 99.99%** (Max 4.38m downtime) | Up to **50% - 100% Service Credit** rebate |
| **API Read Latency** | **P95 < 60ms**, **P99 < 120ms** | **P95 < 80ms**, **P99 < 150ms** | Real-time APM telemetry alerting |
| **Cart & Checkout Latency** | **P95 < 120ms**, **P99 < 220ms** | **P95 < 150ms**, **P99 < 300ms** | Auto-scaling Karpenter container pool |
| **P1 Incident MTTA / MTTR** | MTTA ≤ **15 mins**, MTTR ≤ **60 mins** | MTTA ≤ **5 mins**, MTTR ≤ **30 mins** | 24/7 dedicated War Room & SRE rotation |
| **Disaster Recovery (RPO / RTO)** | **RPO ≤ 15 mins**, **RTO ≤ 1 hour** | **RPO ≤ 5 mins**, **RTO ≤ 30 mins** | Multi-region active-passive failover |

## 💻 Interactive SLA & Contract Explorer Portal

The repository comes with a modern, glassmorphic single-page web application located in the `web/` folder:

*   **SLA Uptime & Service Credit Calculator:** Input your monthly subscription fee and monthly downtime in minutes to compute exact uptime percentage and eligible service credit refund.
*   **Incident Severity & MTTR Lookup:** Interactive matrix for P1-P4 incidents with real-time response targets.
*   **Bilingual Document Browser:** Switch between English and Turkish versions with 1-click copy-to-clipboard for contractual clauses.

To launch the web portal locally:
```bash
# Option 1: Open directly in your browser
open web/index.html

# Option 2: Using Python HTTP server
python3 -m http.server 8080 --directory web
# Then visit: http://localhost:8080
```
